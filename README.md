FlowDesk - Inventory & Data Dashboard 
Project Overview
FlowDesk is a user-friendly web dashboard built to help businesses track their products and manage their daily data. It takes raw sales numbers and turns them into clear charts and alerts, making it a perfect tool for daily desk operations and data analysis. The tool helps teams answer everyday business questions: what items to order, when to order them, and how much cash is tied up in the warehouse.  
Key Features
Live Data Tracking: The dashboard includes an easy form to log daily sales, new purchases, and customer returns. Every time new data is entered, the system instantly updates the stock numbers and graphs.  
Predicting Future Sales: FlowDesk uses past sales data to estimate what customers will buy over the next 30 to 90 days. It draws a clear line chart showing expected demand so managers can plan their next moves.  
Smart Stock Alerts: The tool constantly checks current stock levels against target goals. If an important item runs too low, the system automatically creates a warning alert so the team knows it is time to reorder.  
Financial Health Checks: It tracks how fast products are selling and shows how much money is sitting on the shelves. It also calculates how much cash the business saves by using smarter ordering rules.  
Easy Reporting: Users can export all the current data into Excel or PDF files with a single click. This makes it easy to share daily numbers and progress reports with the rest of the company.
